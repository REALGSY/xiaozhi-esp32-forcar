# An MCP-based Chatbot

（中文）

## 介绍

MacBot AI 聊天机器人作为一个语音交互入口，利用 Qwen / DeepSeek 等大模型的 AI 能力，通过 MCP 协议实现多端控制。此项目是基于开源小智修改而成，用于澳门车载机器人开发。

## 项目背景

编译环境：
使用5.5.1 idf.py build手动编译
编译前需选择芯片esp32s3和watcher板子，可参考：https://icnynnzcwou8.feishu.cn/wiki/JEYDwTTALi5s2zkGlFGcDiRknXf

## 关于项目
开发进程：客制化中。
这是一个由虾哥开源的 ESP32 项目修改而来，以 MIT 许可证发布，允许任何人免费使用，修改或用于商业用途。
